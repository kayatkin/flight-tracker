# Changelog

Все значимые изменения проекта документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.1.1] — 2026-09-10

### Добавлено

- Сброс отложенного сохранения при скрытии вкладки / закрытии Mini App
- Подтверждение закрытия Telegram, пока билет ещё не ушёл в облако
- Индикатор сохранения в шапке: «Сохранение…» / «Сохранено» / «Не сохранено» + Повторить
- Закрытие окон шаринга и присоединения по Escape
- Живое обновление темы Telegram и системной dark/light

### Исправлено

- Копирование ссылки в WebView, где `navigator.clipboard` недоступен

### Безопасность

- GitHub Pages больше не деплоится, если lint / typecheck / test красные
- Удалена неиспользуемая зависимость `@telegram-apps/sdk`

## [1.1.0] — 2026-09-08

### Добавлено

- Редактирование сохранённого билета с тем же UUID
- Дублирование билета (новый UUID, сегодняшняя дата поиска)
- Экспорт видимой истории в CSV (UTF-8 с BOM)
- Каталоги подсказок городов и авиакомпаний (без жёсткой валидации)
- Баннер режима редактирования и закрытие графика по Escape

### Изменено

- Группа в истории раскрывается по заголовку, а не по всей карточке
- Поиск учитывает регистр по `ru-RU`; счётчик показывает «найдено из всех»
- Склонение «пассажир / пассажира / пассажиров»
- Кнопки на карточке с зоной нажатия 44×44

### Безопасность

- См. отдельный [docs/SECURITY.md](./docs/SECURITY.md): что можно коммитить, как ротировать ключи, какие миграции обязательны

## [1.0.0] — 2026-05-10

### Добавлено

- ✈️ Форма добавления рейсов: oneWay / roundTrip, пересадки, прилёт на следующий день
- 📊 Анализ цен: сравнение с лучшим ранее сохранённым (±500 ₽ порог)
- 📈 Сезонный график цен (Chart.js) — минимальная цена по месяцам
- 📱 История рейсов в стиле iOS Wallet с группировкой и поиском
- 👥 Система совместного доступа (sharing):
  - Создание одноразовых ссылок с правами view/edit
  - Присоединение по токену через Telegram бота
  - Список активных сессий доступа
- 🔐 Гостевой режим с хранением данных в localStorage
- 🤖 Telegram бот: /start, /start share\_\<token\>, /help
- 🎨 Адаптивная тёмная/светлая тема через Telegram Theme API
- 🧪 Unit-тесты: validation (11), flightAnalysis (10), seasonalChart (12)
- 🚀 CI/CD: автоматический деплой на GitHub Pages через Actions
- 📦 Feature-based архитектура
- 🎯 Design tokens (CSS-переменные)

### Исправлено

- Исправлена обработка Telegram ссылок и гостевого режима
- Исправлен camelCase/snake\_case в Telegram API
- Исправлено дублирование информации о госте в интерфейсе
- Исправлена ошибка `closeModal is not defined`
- Убран неиспользуемый импорт GuestIndicator из HistoryView
- Исправлено копирование ссылки в SharedSessionsList
- Исправлена обработка share token

### Изменено

- Упрощён дизайн секции стоимости
- Убран дубликат заголовка в секции авиакомпании
- Убрана избыточная подсказка в секции авиакомпании
- Убраны избыточные иконки пассажиров
- Улучшен UX ссылок для совместного доступа
- Компактный дизайн карточек приглашений
- Улучшена адаптация карточек для мобильных устройств
- Улучшен заголовок ShareFlightModal
