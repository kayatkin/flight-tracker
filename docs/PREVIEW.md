# Превью визуального редизайна

Это **не production**. Ветка `cursor/visual-preview-32f4` не для merge в `main`.
GitHub Pages и Mini App не меняются, пока ветку не вольют (не вольём без явного «да»).

## Как посмотреть

На Mac, в каталоге репозитория:

```bash
git fetch
git checkout cursor/visual-preview-32f4
npm run dev
```

Откройте `http://localhost:5173/flight-tracker/` и войдите как обычно. Сверху жёлтая плашка «Превью дизайна».

Без входа, только сетка с примерами:

    http://localhost:5173/flight-tracker/#design-preview

Вернуться на рабочую версию:

```bash
git checkout main
```

## Что меняется только здесь

- Шире сетка истории: на большом экране две колонки маршрутов, в Telegram по-прежнему одна
- Карточки маршрута и билета в духе посадочного талона: крупные города, цена отдельно
- Вкладки-«пилюли», мягче тени и скругления
- Те же кнопки, поиск, CSV, курс ЦБ, шаринг — логика не трогалась
