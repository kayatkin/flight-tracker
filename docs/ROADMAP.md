# Что ещё доработать

Короткий бэклог после истории (правка / копия / CSV) и этого слоя. Не ломает текущий Mini App, пока не трогаем пункты с миграцией.

- Документация: USER_GUIDE, SECURITY, Vite вместо CRA
- Не терять билет, если Mini App закрыли в эти 2 секунды autosave
- Escape в модалках, живая тема, деплой только после зелёных тестов
- Индикатор «сохранено / ошибка» в шапке
- Не потерять черновик правки при уходе на «История»
- Focus trap в модалках
- Бот без service role, проверка functions в CI
- Поиск в истории не сбрасывается при смене вкладки
- Бот на Node 20: lookup через `fetch`, без supabase-js
- Отмена удаления билета из тоста
- Черновик новой формы после обновления вкладки
- Сортировка истории (маршрут / цена / дата поиска)
- Необязательная заметка на билете
- CI для RLS на временной Postgres и `npm audit` фронта
- Error Boundary, черновик правки, per-row save, хеш share-токена, CORS allowlist
- Деплой Pages ждёт полный CI, включая RLS и Deno functions
- Coverage в CI, ESLint бота, deno lint functions, чистка мёртвого CSS
- Компактная панель истории, потолок высоты заметки, CSV по маршруту
- Вход по email в браузере (регистрация, сброс пароля), Mini App в Telegram без изменений
- Связка Telegram ↔ email: кнопка «Аккаунт», пароль обязателен, истории сливаются без молчаливой потери билетов
- Настоящий refresh для Telegram/гостя (opaque-токен, не копия access) и каталог русских строк вместо JSX
- Dual-key JWT: ES256 с `kid` при своём JWK, проверка HS256 и JWKS, `link-email` без gateway verify
- Сессии гостя: demotion на refresh, отзыв при выходе, атомарный bind, лимит частоты, CSP, пароль 8

## Можно делать дальше без ломки продукта

Пока пусто: пункты из прошлого бэклога закрыты. Новое — только по явной задаче.

## Только с отдельным окном и явным «да»

- Монетизация / Stars / i18n EN+RU с ветки `feature/monetization-i18n` — большой конфликт с текущей `main`, не мержить вслепую.
- Сайт-аналог на VPS: тот же SPA уже умеет вход по email; VPS — отдельный хостинг, не форк кода.
- Смена визуального языка карточек и сетки экрана.
- Отозвать legacy JWT Secret и перейти на publishable/`sb_` API keys — ломает GitHub Pages `VITE_SUPABASE_ANON_KEY`, пока клиент не сменит ключ.
